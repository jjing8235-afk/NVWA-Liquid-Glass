# NVWA 液态玻璃

SillyTavern（酒馆）美化扩展：iOS 风格的折射玻璃、白天瓷白 / 晚上墨黑自动切换、名片式头像、模型思考时的点阵小球。

作者：zytteell8698

## 安装（三选一）

**方法一：酒馆助手一键安装（推荐）**

1. 下载 [`install/NVWA 液态玻璃 · 酒馆助手安装脚本.json`](install/)。
2. 酒馆助手 → 脚本库 → 导入，选这个文件，导入到「全局脚本」。
3. 打开这个脚本的开关，按提示点「安装」，页面会自动刷新。
4. 以后点脚本按钮「检查更新」就能更新。

**方法二：酒馆自带的扩展安装**

扩展（拼图图标）→ 安装扩展，粘贴：

```
https://github.com/jjing8235-afk/NVWA-Liquid-Glass
```

**方法三：配套美化主题（建议和上面任一方法一起用）**

下载 [`install/NVWA 液态玻璃 · 美化主题.json`](install/)，在「用户设置 → UI 主题」右边点导入，然后在下拉框里选「NVWA 液态玻璃」。主题会把聊天风格设成气泡、头像设成圆角，美化依赖这两项。它不带自定义 CSS，不会覆盖你自己写的 CSS。

## 装好以后

- 第一次运行会把「瓷白」「墨黑」两张壁纸放进背景库。选其中一张当壁纸，之后就按时间自动换深浅色。
- 所有开关在 扩展 → NVWA 液态玻璃 里。
- 边缘折射只在 Chrome / Edge 内核生效，其他浏览器自动换成模糊玻璃。
