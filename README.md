# NVWA 液态玻璃

**当前正式版本：2.0.2（2026-11-12）**

SillyTavern / TT 外观扩展。提供通透玻璃、深浅配色、悬浮输入区与阅读样式，保留角色卡自己的内容与交互。

本次修复与复测说明见 **[2.0.2 更新日记](更新日记-2.0.2.md)**；逐版记录见 [CHANGELOG.md](CHANGELOG.md)，检查结果与适用边界见 [VALIDATION.json](VALIDATION.json)。

## 2.0.2 更新

修复部分手机上采集按钮的白底浅字，深浅配色都保持可读；每种复测提供三步操作说明，明确提前结束的原因与导出时机。

## 2.0.1 更新

黑白壁纸缺失时会检查并补回，列表尚未加载时刷新后继续切换。更新并刷新即可重试，无需先删除已有背景或反复卸载扩展。

需要反馈手机问题时，打开“玻璃设置 → 高级与兼容 → 导出诊断”，选择主要复测现象并开始 15 秒采集。完成后点击屏幕提示条上的“导出诊断”，发送这一份 TXT 即可；操作步骤见 [手机复测说明](IOS-TESTING.md)。采集只在手动开始后运行，未观察到的操作会列出。

本次同时包含 iOS 键盘与 Android WebView 超长消息兼容处理。对应手机上的屏闪、键盘和拖动体验仍需原设备验收；诊断数据不自动判定肉眼屏闪。

## 2.0 带来了什么

- **映卿、漾卿、澄卿**：三种玻璃路径，材质与预设分组展示，既有调节继续兼容。
- **青瓷、栖暖、笺月、晴笺**：四款阅读风格，配合字号、行距、缩进及消息内阅读滤镜。
- **御风性能引擎 / 棱光折射引擎**：高楼层拖动更跟手，输入区菜单和快捷回复更利落，通透玻璃继续保留细致弧面与反光层次。
- **更清楚的设置工作台**：外观与材质、界面布局、阅读文字、高级与兼容分开组织；“我的外观”支持保存、恢复与撤销本次恢复。
- **更顺手的操作**：顶栏一个折叠入口，最多自选两个常用图标放在左侧；图标选板、胶囊滑块与共享数值浮标统一呈现。
- **高透与可读性并存**：图标随局部背景调整深浅，柔光滤镜限定在消息背景；卡片保留作者底色、渐变和透明度。

## 已安装用户如何更新

从正式仓库安装的用户，在扩展管理中检查更新并刷新酒馆，工作台底部应显示 **2.0.2**。已有外观与材质设置继续兼容，配套主题无需仅因版本号变化重新导入。

从测试仓库安装的用户，请先停用测试版，再从下方正式地址安装并启用，只保留一份运行。正式库与测试库是不同更新来源，不会因正式发布自动互相切换。

## 首次安装

1. 先导出自己的 UI 主题与自定义 CSS，保存现有外观。
2. 下载 [NVWA 液态玻璃 · 美化主题.json](install/NVWA%20液态玻璃%20·%20美化主题.json)，在“用户设置 → UI 主题”中导入，并在下拉框明确选中“NVWA 液态玻璃”。只导入不等于已经应用。
3. 选择一种方式安装扩展。

**方式 A：使用酒馆的扩展安装入口**

在“扩展 → 安装扩展”中填写：

```text
https://github.com/jjing8235-afk/NVWA-Liquid-Glass
```

**方式 B：使用酒馆助手安装脚本**

将 [NVWA 液态玻璃 · 酒馆助手安装脚本.json](install/NVWA%20液态玻璃%20·%20酒馆助手安装脚本.json) 导入酒馆助手全局脚本库，开启后按提示安装。脚本保留主题前置检查、安装确认与“检查更新”按钮。

## 常用设置

在“扩展 → NVWA 液态玻璃”中打开玻璃设置，也可使用折叠菜单里的外观工作台入口。

| 位置 | 可以调整什么 |
| --- | --- |
| 外观与材质 | 玻璃材质、弧度、深浅切换、壁纸与外观存档 |
| 界面布局 | 顶栏常用入口、输入区、楼层显示、悬浮球拖动与融合 |
| 阅读文字 | 四款文字风格、字号、行距、缩进与消息背景滤镜 |
| 高级与兼容 | 御风性能相关选项、棱光折射方式、环境适配与诊断 |

手机姿态高光开启后会尝试恢复使用；浏览器要求系统授权时仍需用户允许。关闭开关会停止相应监听。诊断导出不包含聊天正文、草稿、角色名、壁纸地址与账号配置。

## 兼容与验证

不要同时开启多份 NVWA 或其他整页美化扩展。配套主题不会替你关闭其他扩展，插件也不会自动清空自定义 CSS 或覆盖个人主题。

默认按浏览器能力选择渲染路径；需要减轻渲染负担时，可选择澄卿。iOS 默认保留兼容路径，SVG 折射是独立实验，仍以 [iOS 测试说明](IOS-TESTING.md) 为准。

自绘卡片的玻璃使用独立背景层，保留固定浮窗定位。可访问 iframe 与独立浮层保留相应清理边界；跨域和沙盒隔离继续生效。预设 / 记忆适配仅限已支持的原生弹窗内容根，不接管业务脚本、提示词、数据与保存逻辑。

测试基线通过 23 项离线回归、52 组反光 RGBA 对照与 4 组 Worker PNG 解码像素对照；正式包另行检查版本、安装资源、源码一致性与实际宿主加载。240 层 / 4 倍 CPU 降速的桌面模拟显示魔杖首开和快捷回复开关有改善，**不代表实际手机 FPS、INP 或所有卡片的兼容保证**。首次加载、复杂卡片和宿主扩展仍可能带来额外开销。

## 退出与恢复

先关闭扩展的美化开关；需要卸载时，在扩展管理中停用或卸载，再切回自己的主题与 CSS 备份。切换到测试版或另一份安装前，先停用当前版本，避免重复加载。

配套主题的导入、删除与更新由用户手动完成。请保留个人主题备份，不删除其他主题。
