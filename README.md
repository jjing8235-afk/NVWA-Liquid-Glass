# NVWA 液态玻璃

**当前版本：1.4.2**。SillyTavern / TT 通用美化扩展：边缘折射玻璃、瓷白 / 墨黑深浅切换、悬浮输入区与角色目录。

本版合入已验收的 ST / TT 通用兼容与显示修复；已安装正式仓库的用户直接检查更新，完成后重启或强制刷新，确认版本为 1.4.2。已有配套主题无需重新导入。

作者：zytteell8698

## 安装顺序：先主题，后插件

### 1. 先备份旧主题

在「用户设置 → UI 主题」里导出当前主题，自己粘贴的自定义 CSS 也建议单独保存。
**配套主题将自定义 CSS 设为空，并调整配色、气泡、头像、阴影等 UI 参数。没有备份就不要直接覆盖自己精心调整的主题。**

### 2. 导入并选中配套主题

下载 [NVWA 液态玻璃 · 美化主题.json](install/NVWA%20液态玻璃%20·%20美化主题.json)。
在「用户设置 → UI 主题」右侧导入，然后在下拉框中明确选择「NVWA 液态玻璃」。
**只导入文件不等于所有设置已经应用，必须选中一次。**

主题只提供底座，不包含重复的插件 CSS、脚本或远程资源。减少动态效果的偏好不被主题覆盖。

### 3. 安装插件（二选一）

**方法 A：酒馆自带扩展安装**

扩展 → 安装扩展，粘贴：

```
https://github.com/jjing8235-afk/NVWA-Liquid-Glass
```

**方法 B：酒馆助手安装脚本**

导入 [NVWA 液态玻璃 · 酒馆助手安装脚本.json](install/NVWA%20液态玻璃%20·%20酒馆助手安装脚本.json) 到酒馆助手的全局脚本库，打开脚本开关并按提示安装。
尚未选中配套主题时，脚本只提示准备主题，不执行安装。装好后会刷新；按钮「检查更新」用于后续更新。

## 使用与冲突边界

- 首次运行会将瓷白、墨黑两张壁纸加入背景库；选其中一张可按时间自动换深浅。
- 设置位于「扩展 → NVWA 液态玻璃」。插件会显示主题未导入、未选中或关键选项改变的提示，但不会自动切主题或清空 CSS。
- 喜欢首行缩进时，在同一设置面板打开「普通正文首行缩进两个汉字」。默认关闭，只影响普通正文段落；列表、代码、引用块及自带样式面板不接管，也不修改聊天原文。
- 不要同时启用其他整页美化扩展。选择配套主题不能阻止另一扩展写入样式；本插件不会自动关闭其他扩展，也不修改角色卡或世界书内容。
- 默认按内核能力自动适配，无需勾选“是不是 TT”。ST Chromium 保留原路径；符合模糊及 SVG URL 语法门槛的安卓 WebView 自动尝试兼容折射。不满足条件时使用模糊降级；显示异常可选“环境适配 → 仅模糊”，该选择会保存。
- iOS 默认兼容模糊。独立 SVG 折射实验放在“玻璃细调参数”内，默认关闭；真实 iOS 折射仍待实机确认。详见 [iOS 测试说明](IOS-TESTING.md)。
- 玻璃细调参数默认折叠，减少手机滚动误触；收起不会改变已保存数值。
- 原生扩展列表、删除角色和新建聊天确认项显示清楚的勾选状态；不改删除、启停或保存逻辑。
- 卡内面板、可访问的消息 iframe，以及宿主核心区之外的独立浮层自动去掉文字阴影。按固定定位或弹窗/菜单语义识别，不依赖特定卡名或 ID，不增加开关。自绘卡片所在消息避开外层玻璃叠加，面板移除后恢复。

## 第三方特色弹窗

酒馆原生通用弹窗保留外壳和原生控件适配，不补强制关闭按钮。第三方窗口不接管布局、交互或保存逻辑；对宿主核心区之外可见的固定定位或带弹窗语义的独立浮层，只自动清理文字阴影。关闭、重开或重新创建后会重新识别；关闭美化会撤去标记和运行时样式。

可访问的消息/浮层 iframe 支持加载、重载和嵌套前端。跨域或沙盒隔离的内容保持隔离，不改 iframe 源码。无语义的任意绝对定位容器、文字描边、图形滤镜或重复文本等重影来源不保证覆盖；未知组合仍需现场检查。

已确认兼容的例外：NVWA 预设面板与 NVWA 记忆界面保留专门的深浅色玻璃适配。仅匹配酒馆原生 Popup 内直接承载的 `#nvwa-panel` / `#nvwa-memory`；不扩展到其他记忆插件，不修改预设文件、提示词、记忆数据或保存逻辑。

## 验证与边界

本版由 1.4.2-tt.6 提升为正式版，用户已反馈测试无异常并授权发布。自动化包含 26 项适配检查、6 个桌面环境的 65 项交互检查，以及勾选、折叠、卡片/iframe、通用浮层和来源隔离检查。功能代码沿用已验收版本，验证记录见 [VALIDATION.json](VALIDATION.json)。

桌面浏览器、模拟手机身份和隔离宿主不能替代真实 iOS 内核；iOS 真机折射、客户端安装渠道及长聊天性能仍待验收。只读 DOM 检查与用户验收分别记录，不写成自动化已经完成实机安装。

## 更新配套主题

SillyTavern 1.18 不允许导入同名主题。已装旧版时，先导出旧主题和自定义 CSS 作备份，切到另一主题，再手动删除旧的「NVWA 液态玻璃」，导入新版并在下拉框选中。
**不要删除自己的其他主题。** 插件不会自动删除、覆盖或更新主题文件。

## 退出与恢复

先关闭本插件的美化开关，或在扩展管理中停用并刷新，再导入、选择安装前导出的旧主题；必要时粘回单独备份的自定义 CSS。
新流程不在后台保存或恢复用户主题；旧版本曾留下的备份字段仍保留，但当前没有一键还原按钮。
