# Liquid Glass Web adaptation · local.9

Source: https://github.com/xiaofangstudio/liquid-glass-web, main verified as 3094add905e60ee5aeb45e806751beb94425dd73 (2026-10-22). README declares MIT; original refraction work credits Shu Ding (2025). Attribution and original license stay in LICENSE-liquid-glass.txt. Upstream code and algorithm documentation were read; no upstream script was executed.

The upstream showcase has five controls: ref (refraction scale), edge (refraction ring thickness), rad (shape roundness), tint and blur, with one default recipe (1 / 1 / 0.6 / 0.08 / 0.25). No additional named preset system was found at this commit. web-presets.js uses exactly these five fields. clear equals the upstream default; thin, soft and crystal are NVWA adjustments around it, not upstream official presets.

Since 2026-11-05 (user decision: as close to upstream as possible) sampleWebDisplacement is the upstream fragment on whole-element normalized coordinates: roundedRectSDF(ix, iy, .3, .2, rad), s = smoothStep(0, 1, smoothStep(.8, 0, d - .15 / edge / strength)), offset = (ix*s + .5)*W - x. Normalization follows upstream: peak *= .5, map = raw / peak + .5 (byte-clamped), feDisplacementMap scale = peak * ref. The centre is flat and the ring bends strongly. One deliberate NVWA deviation (user request 2026-11-05, "把两端收一点"): upstream normalizes by the whole width, so long capsules get huge end rings (374x52 input: ~58 px peak offset, 624x52: ~98 px, with visible streaks). END_ASPECT = 3 caps the normalized length at 3x the short side; the extra length becomes a flat middle where only the top/bottom ring bends. Shapes up to 3:1 (small islands) are byte-identical to upstream; both input widths now peak at a filter scale of ~24 (about 12 px real offset). The input pill also passes bendY = 1.5 (user request: a little more top/bottom bend), which thickens only its top/bottom ring; islands use 1. The old 2.6 px narrow-band variant is gone. Maps use at most one texel per CSS pixel, stay bounded (20 maps / 1.57 MP) and are keyed by rounded width, height, preset and strength; the shape itself comes from the host border-radius. Original glass keeps its separate physical/legacy path and restored original refraction geometry. Web uses a separate -web filter ID; source selection and recipe changes cannot mutate Original maps or parameters. Web fallback blur follows its own recipe.

The chain is upstream's url(#id) blur(<recipe>px) contrast(1.2) brightness(1.05) saturate(1.1), white tint rgba(255,255,255,<recipe tint>) in both tones, and upstream shadow 0 4px 8px rgba(0,0,0,.22), inset 0 -8px 20px rgba(0,0,0,.14). Upstream's volumetric light, press glow, mutual illumination and white rims are deliberately not ported (no-highlight rule); the Web material has no light/--ilg-web-lit/x/y path. Press on a top-bar island: scale(1.1, .955) while held and refraction strength 1.3 (one map rebuild), then a 500 ms spring k = .1·exp(-5t)·cos(9t), scale(1+k, 1-.45k). Only islands deform; the input pill and icons never transform. Reduced motion (system or ST setting) disables the squash and spring.

The independent workbench owns material selection and Web recipes. Settings use the existing iosLiquidGlass namespace and S.v=9, with webPreset and a conservative materialRevision migration. No remote scripts, photos, dependencies, full-screen demo singleton or global dragging.

iOS remains conservative system blur/light, with SVG experiments opt-in. Synthetic device events do not prove Apple WebKit refraction, physical sensor behavior, keyboard safety or long-session phone performance. Local-only; no repository publish.
